# 立绘素材

`hana-coding.png` 与 `hana-coding.webp`：参考《偶像大师 闪耀色彩》鈴木羽那官方形象，经内置 image_gen 生成的 Coding 立绘与职场服装编辑版，非官方原图。

采用用户选定的第一张职场穿搭版，并用内置 image_gen 清理头发的波纹高光。PNG 为清理输出；WebP 为保留完整 RGBA 像素的无损编码，均为 1024×1536。清理前版本保存在 hana-coding-original.png 与 hana-coding-original.webp。原始角色版权归原权利人所有。

官方参考链接、完整生成提示词和接入说明见 [ARTWORK_AND_MOTION.md](../../docs/ARTWORK_AND_MOTION.md)。
