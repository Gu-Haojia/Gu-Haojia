# 立绘素材

- `hana_old-coding.webp`：个人主页此前选定的职场羽那，保留原始文件字节；对应 `character: "hana_old"`，不参与 `random`。
- `hana-coding.png` 是该旧版的透明 PNG，`hana-coding-original.png` / `.webp` 是清理头发前的备份。旧版生成与编辑过程见 [ARTWORK_AND_MOTION.md](../../docs/ARTWORK_AND_MOTION.md)。
- 其余 28 张 `*-coding.webp`（含 `hana-coding.webp`）：来自 [shinycolors-profile-template](https://github.com/Gu-Haojia/shinycolors-profile-template) 的职场 / Coding 同人立绘。逐位通过 OpenAI 内置 imagegen，使用对应官方原始角色形象作为参考生成，1024×1536，透明背景，无损 WebP。完整提示词和官方参考链接见 [生成记录](../../docs/character-prompts.json)。

均为非官方同人衍生图，原角色相关权利归原权利人。角色清单与随机池设置见 [`data/characters.json`](../../data/characters.json)，使用方法见 [角色选择](../../docs/CHARACTERS.md)。
